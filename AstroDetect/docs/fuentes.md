# Fuentes y trazabilidad

Consulta de documentación: 26 de octubre de 2026. Las fuentes institucionales explican el método y las herramientas; el informe final deberá integrar además bibliografía académica pertinente y citada de forma consistente.

- [NASA — What's a transit?](https://science.nasa.gov/exoplanets/whats-a-transit/): fundamento de ocultación y medición indirecta; no valida el detector propuesto.
- [IAU — Resoluciones 2015, B3](https://www.iau.org/static/resolutions/IAU2015_English.pdf): constantes nominales de conversión utilizadas por el diseño científico.
- [Astropy — Constants](https://docs.astropy.org/en/stable/constants/index.html): documentación de implementación de constantes IAU2015; referencia, no dependencia del navegador.
- [GitHub — What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages): alojamiento estático y disponibilidad en repositorios públicos con GitHub Free.
- [GitHub — GitHub Pages limits](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits): restricciones y cuotas; el plan no promete capacidad ilimitada.
- [Vite — Deploying a Static Site](https://vite.dev/guide/static-deploy.html#github-pages): build y base de una subruta de proyecto.

La fórmula de intersección de discos, el muestreo y el umbral por mediana/MAD son decisiones matemáticas y técnicas del diseño. Deben comprobarse mediante pruebas independientes. No se presentan como un algoritmo de NASA ni como un método calibrado de confirmación astronómica.
